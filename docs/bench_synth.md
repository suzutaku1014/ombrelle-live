# ベンチマーク

入力 `synthetic` / 精度評価 `data/synth` の val split / device `mps`

## 速度とサイズ

前処理 + forward + 読み戻しを含む1フレームの推論時間。teacher と student を
交互に測ってGPUの熱ドリフトを相殺している。

| モデル | パラメータ | median | p90 | min | std | FPS(推論のみ) |
|---|---|---|---|---|---|---|
| teacher (Depth Anything V2 Small) | 24.79 M | 17.9 ms | 23.9 ms | 16.5 ms | 5.6 | 56 |
| **student (自作蒸留)** | **0.97 M** | **7.0 ms** | **7.8 ms** | 6.6 ms | 0.6 | **142** |

パラメータ **25.4x 削減**、推論 **2.54x 高速化**。
パラメータ比ほど速くならないのは、この規模だとカーネル起動と
メモリ帯域が支配的で FLOPs が律速ではないため。

## 精度 (教師を基準にした相対深度、正規化 [0,1])

| 指標 | student |
|---|---|
| MAE | 0.0171 |
| 誤差 < 0.05 の画素率 | 0.935 |
| 誤差 < 0.10 の画素率 | 0.979 |
| AbsRel (gt>0.05 でマスク) | 0.0793 |
| RMSE | 0.0330 |

AbsRel は正規化した目標値に対しては gt≈0 (最遠) で発散するため、gt>0.05 でマスクして算出している。

## 時間的一貫性 (連続フレーム間の平均絶対差、小さいほど絵が落ち着く)

| モデル | 毎フレーム min-max | 非対称 EMA 正規化 |
|---|---|---|
| teacher | 0.0072 | 0.0083 |
| student | 0.0045 | 0.0046 |

この表が本題。深度は絵のパラメータ(筆サイズ/彩度/霞)を駆動するので、1 枚の精度よりフレーム間の落ち着きが体験を支配する。毎フレーム min-max 正規化と非対称 EMA を比べると、teacher で 0.9x、student で 1.0x の差が出る。
